# Do Not Wake

Камерная игра о ремонте робота в одной мастерской. НТО РКИ 26/27, II этап, команда **Evilbyte Studio**.

## Запуск

1. Открыть `project.godot` в **Godot 4.3** (стандартная сборка, без .NET).
2. F5 — запуск.

На этой машине редактор: `GODOT_BIN`.

## Сейчас в прототипе

- Выбор инструмента (тряпка / отвёртка / клавиатура) и применение к зоне робота.
- Правильный инструмент чинит зону, неправильный повышает нестабильность.
- Нестабильность растёт сама по себе; при пороге робот просыпается — надо замереть (не двигать мышью 6 секунд).
- Успех / провал смены и перезапуск по ЛКМ.

Всё это — каркас для записи трёх видео в блок «Геймдизайн» (Core Loop, Game Loop, User Flow).

## Структура

```
scenes/     сцены
scripts/    логика (GDScript)
assets/     спрайты, звуки, UI
data/       JSON с параметрами (баланс, состояние робота)
docs/       архитектура и заметки
```

## Важно

- Движок: Godot 4.3, версия указывается в презентациях.
- Никаких платных ассетов. Сторонние — в `Источники.pdf`.
