# Do Not Wake

Камерная игра о ремонте робота в одной мастерской. НТО РКИ 26/27, II этап, команда **Evilbyte Studio**.

## Запуск

1. Скачать **Godot 4.7.2** (standard, не .NET): https://godotengine.org/download/windows/
2. Распаковать архив в любую папку (установка не нужна).
3. Открыть в редакторе `project.godot` → F5.

У нас распакован здесь:
`GODOT_BIN`
(архив распаковался в папку с именем как у exe — внутри неё лежит сам `.exe` и `_console.exe` для запуска из терминала).

Проверено: проект открывается и запускается в **4.7.2.stable.official**, ошибок нет, `project.godot` движок не переписывал.

Проект создавался в Godot 4.3. При первом открытии в 4.7.2 редактор предложит обновить проект — согласиться. После апгрейда проверить, что сцена запускается без ошибок, и закоммитить изменения `project.godot`.

Для сборки Windows нужны **export templates 4.7.2**: `Editor → Manage Export Templates → Download and Install` (отдельный архив `export_templates.tpz`, ~1 ГБ).

## Сейчас в прототипе

- Выбор инструмента (тряпка / отвёртка / клавиатура) и применение к зоне робота.
- Правильный инструмент чинит зону, неправильный повышает нестабильность.
- Нестабильность растёт сама по себе; при пороге робот просыпается — надо замереть (не двигать мышью 6 секунд).
- Успех / провал смены и перезапуск по ЛКМ.

Всё это — каркас для записи трёх видео в блок «Геймдизайн» (Core Loop, Game Loop, User Flow).

## Структура

```
scenes/     сцены
scripts/    логика (GDScript)
assets/     спрайты, звуки, UI
data/       JSON с параметрами (баланс, палитра, состояние робота)
docs/       стиль, архитектура, документы команды
```

## Стиль

- `docs/style.md` — палитра из 15 цветов с ролями, правило 60/30/10, рэмп робота, правила света и UI.
- `docs/palette.png` — шпаргалка с квадратами и hex.
- `data/palette.json` — те же цвета для кода, hex не хардкодим в скриптах.
