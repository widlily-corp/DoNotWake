# Do Not Wake

Камерная игра о ремонте робота в одной мастерской.

**Жанр:** симулятор ремонта с хоррор-напряжением · **Платформа:** ПК (Windows) · **Движок:** Godot 4.7.2 (standard) · **Команда:** Evilbyte Studio

## Запуск

1. Скачать **Godot 4.7.2** (standard, не .NET): https://godotengine.org/download/windows/
2. Распаковать архив в любую папку — установка не нужна.
3. Открыть в редакторе `project.godot` → F5.

Для сборки под Windows нужны **export templates 4.7.2**: `Editor → Manage Export Templates → Download and Install`.

Если окно открывается чёрным, запускать через `tools\run_game.bat` и `tools\run_editor.bat`: они принудительно ставят Vulkan-драйвер, на котором сцена рисуется корректно. Если Godot не в `PATH`, перед запуском задать `GODOT_BIN` — полный путь к `Godot_v4.7.2-stable_win64.exe`.

## Что в прототипе

Смена целиком: диагностика → выбор неисправной детали → картотека регламентов ТО → ремонт узла → проверка → следующая деталь → отчёт о заказе.

- **Три этапа ремонта:** тактильная чистка ветошью (контроль скорости трения), демонтаж бронелюка отвёрткой (4 болта, срыв шлица), пуповинный кабель (совмещение паза и фиксация замка).
- **Шесть деталей смены** (всё из `data/parts.json`, код не меняется): `srv_04` сервопривод плеча, `pwr_02` силовая шина, `opt_07` блок оптики, `hyd_01` демпфер стопы, `cool_03` радиатор охлаждения, `sens_05` датчик кисти. У каждой — карточка ТО в своём ящике картотеки (`data/documents.json`).
- **Напряжение:** нестабильность растёт сама и от ошибок; при пороге робот просыпается — нужно замереть (5 секунд без движения мыши). Лимит 4 пробуждений, таймаут смены 900 с, пауза с кулдауном.
- **Подача:** вступительная кат-сцена, записи и регламенты на ЭЛТ-экране, процедурная анимация робота (дыхание, дрожь, оптика, тепловые эффекты), параллакс 2.5D.
- **Данные вынесены из кода:** `data/parts.json`, `data/documents.json`, `data/robot.json`, `data/palette.json`.

## Тесты

```
powershell -File tools/run_all_tests.ps1
powershell -File tools/run_all_tests.ps1 -GodotPath "C:\Godot\Godot_v4.7.2-stable_win64_console.exe"
```

Набор автотестов на GDScript, запускается в headless-режиме Godot. Путь к движку берётся из `-GodotPath`, переменной `GODOT_BIN` или `PATH`.

## Сборка

```
godot --headless --path . --export-release "Windows Desktop" build/DoNotWake-v0.2.0.exe
```

В `build/` появятся `DoNotWake-v0.2.0.exe` и `DoNotWake-v0.2.0.pck` (папку `build/` не коммитим — она в `.gitignore`).
Нужны export templates 4.7.2. Версия в имени файла — та, которую тестируем на плейтесте.

## Структура

```
scenes/     сцены
scripts/    логика (GDScript)
assets/     спрайты, звуки, UI
data/       JSON с параметрами (баланс, палитра, состояние робота)
docs/       стиль, архитектура, спеки
```

## Стиль

- `docs/style.md` — палитра из 15 цветов с ролями, правило 60/30/10, рэмп робота, правила света и UI.
- `docs/palette.png` — шпаргалка с квадратами и hex.
- `data/palette.json` — те же цвета для кода, hex не хардкодим в скриптах.
