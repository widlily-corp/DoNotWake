# UI: главное меню (ЭЛТ + VHS)

Идея: игрока встречает вид на старый ЭЛТ-телевизор. На экране — монохромное меню в цвете циан, как служебный экран диагностики. Ниже, в кадре, VHS-привод: кассета и есть кнопка «начать».

Мокап: `docs/ui-mockup.png` (1280×720). Рисовалось в 640×360 и увеличено ×2 — держим пиксель.

## Композиция (координаты в 1280×720)

| Элемент | Прямоугольник |
|---|---|
| Корпус телевизора | x 112–1168, y 32–504 |
| Экран | x 160–1120, y 80–460 (960 × 380) |
| VHS-привод | x 220–1060, y 524–680 |
| Кассета | x 392–888, y 532–628 |
| Play-кнопка (треугольник) | x 904–936, y 568–600 |

Экран занимает 75% ширины — это главный объект, меню читается сразу.

## Элементы экрана

| Элемент | Стиль | Состояния |
|---|---|---|
| Заголовок `DO NOT WAKE` | Cloud White, глитч-двойник в Alert и циане, сдвиг ±2 px | постоянный лёгкий дрейф 1 раз в 3–5 с |
| Подпись `ДИАГНОСТИКА v0.3` | тусклый циан | — |
| Пункт меню | 15 px, циан | обычный / наведение (`Cloud White` + подчёркивание + курсор-треугольник `Alert`) / недоступен (тусклый, без реакции) |
| Статус-строка | `CH 03` · таймкод · `● REC` | REC мигает раз в 1 с |
| Кассета | `Cool Slate`, две катушки, наклейка `DO NOT WAKE` / `СМЕНА 01` | выдвинута / вставляется (0.4 с) / вставлена |
| Play-треугольник | циан, появляется после вставки кассеты | скрыт / активен |

## Поведение

1. **Старт — только через кассету.** Игрок кликает кассету → анимация вставки (0.4 с), щелчок привода, треугольник загорается → через 0.5 с переход в игру.
2. **Пункты меню** работают мышью: «Новая смена» = то же, что кассета; «Продолжить» недоступен в демо (нет сохранений) и честно показан серым; «Выход» закрывает игру.
3. **Наведение** — подчёркивание и курсор-треугольник, без подсветки фона: экран ЭЛТ не умеет «кнопок».
4. **Звук** — гул телевизора, щелчок привода, шум перемотки при старте.

## Анимации

- Мерцание ЭЛТ: яркость ±2%, раз в 2–4 с, кадр 1–2.
- Скан-линии: статичная текстура поверх экрана, сдвиг на 1 px вниз раз в 0.5 с.
- Вставка кассеты: кассета уезжает вправо-вниз в слот на 12 px, гаснет подсветка экрана, затем вспышка помех и переход.
- Переход в игру: 6–8 кадров VHS-помех, звук «трек начинается».

## Как делать в Godot 4.7.2

- `scenes/ui/MainMenu.tscn` — `Control` на весь экран (1280×720).
- Корпус и привод — `TextureRect` (или `NinePatchRect`), экран — отдельный `TextureRect` с содержимым.
- Текст — `Label` с пиксельным шрифтом (m5x7 / Press Start 2P), размер 15–27 px, без сглаживания (`font_antialiasing = none`).
- Скан-линии — либо готовая текстура-оверлей с `CanvasItemMaterial`, либо шейдер: `color.a *= 0.85 + 0.15 * step(0.5, fract(SCREEN_UV.y * 360.0))`.
- Вставка кассеты — `AnimationPlayer` (позиция + модуляция), затем `change_scene_to_file`.
- Звук — `AudioStreamPlayer` (гул зацикленный, щелчок — одиночный).

## Палитра меню

Только `Gunmetal` (фон корпуса), `Steel`/`Slate` (металл привода), `Cool Slate` (кассета), `Cloud White` (заголовок), `Signal` (циан — текст и подсветка), `Alert` (REC и курсор). Остальные цвета в меню не используем.
